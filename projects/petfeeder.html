Automated Pet Feeder

This automated IoT pet feeding system uses a React frontend and a Java backend to let users schedule feeding days, times, and portion sizes through a web dashboard. The backend communicates with an Arduino microcontroller that drives a stepper motor to rotate a multi-slot gear mechanism for precise food dispensing. An integrated ultrasonic sensor monitors the food level inside the storage bin and triggers a notification when a refill is required.
